# 题库范围与核对记录

固定100题，每题1分，四个单元各25题。依据用户提供的五张图片编制，扩展限定为相关分类、方位、交通效率、用水与可持续发展情境。没有加入无关学科。

为避免泄露评分标准，本文件只记录编制依据与处理方式；题目、标准答案和解析的完整审核稿位于管理员本地 `private/bank.json`，数据库也保留完整版本。

## 图片处理

- 图片1、2：第七章1～14题，覆盖土地、供水、植被、湿地、动物、矿产、污染与可持续发展。
- 图片3：第四章1～9题及新城填海区分布图。以SVG重绘相对方位，明确不按比例、不表示当下工程边界。
- 图片4：第五章1～10题。保留产业分类、传统手工业、旅游定位、横琴合作与“1+4”知识。
- 图片5：第六章城市与对外交通。避免把手写的轻轨站数、巴士线路数、路网里程直接当作当下数据。

## 有歧义或有时效性内容的处理

- 历史城区列入名录日期、建筑与广场数量按官方资料核对。
- 大桥“落成”与“正式通车”有区别，排序题明确以正式通车为准。
- 图片中“三座大桥”的旧表述已改为带时间条件的判断题。
- 古树数量最多的表述限定资料及2021年介绍的时间，不声称永久不变。
- 供水题考查水源系统、地点和“原水”含义，不把旧图片中的固定百分比当作实时统计。
- 未将图片中存在划改的某街区工业/住宅分类作为唯一正确答案题。
- 未把图片中旧的“三大支柱产业”叙述当作当下产业结构结论。
- “澳门细蚁”题只考查发现地点及名称，不把尚需进一步科学证据的永久地域独有性当作必考断言。
- 计算及用水图表为相关知识点扩展，题干和解析明确写为练习设定，不冒充官方数据。
- 填空设置明确回答格式与简繁别名，数值题要求不附加单位；选择题和多选题均给出明确判分规则。
